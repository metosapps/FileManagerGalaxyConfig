Privacy Policy

Updated 25 October 2026

File Manager (com.filegx.appsmanager) manages files locally. It has no user account system and does not upload your file contents to an analytics or advertising service. You choose which files to share or transfer.

This build does not transmit Firebase analytics or crash reports. If advertising is allowed by your privacy choices, Google Mobile Ads and UMP may process device, advertising and consent information. File names, paths, search terms and Vault contents are not ad-request parameters. Samsung IAP processes store-account and purchase information for optional purchases. Signed remote configuration fetches disclose an ordinary network request to the configured hosting provider.

Advertising consent, when required, is requested before ad requests. Advertising privacy choices remain available in Privacy settings when UMP requires them. Pro ownership removes ads. First-session, file-operation, Vault, permission and purchase flows do not show ads. Analytics and crash-reporting preferences default off; no Firebase reporting backend is configured in this build.

For File Manager support or privacy questions, contact chennoufo11@gmail.com.

Local preferences stay on the device until cleared or the app is removed. Vault and Trash are not cloud-backed up by the app. Encrypted Vault contents require the passphrase. The optional Wi-Fi feature transfers only files selected for sharing over the local network.

The remote configuration endpoint is hosted on GitHub Pages. GitHub may process ordinary connection metadata such as IP address and user agent. File names, paths and search terms are not included in configuration requests.

Contact chennoufo11@gmail.com for support or privacy questions. You can remove local application data through Android Settings. Advertising privacy controls are offered in-app when required by UMP.
